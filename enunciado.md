# Compiladores – Python

Criar em Python um analisador de pedidos para uma lanchonete.

O sistema deverá identificar ação, produto e quantidade por meio de **análise léxica** e depois
verificar se o pedido é válido por meio da **análise semântica**.

**Ex:**
- Pedir Hamburguer
- Pedir Refrigerante
- Remover Refrigerante
